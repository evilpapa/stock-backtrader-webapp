- 使用回测`latest_holdings.csv`实际持仓及实际权重；未用全部候选股或历史持仓并集。
- 完整明细解析出100条指数投资和23条积极投资，证券代码唯一；公允价值合计2,449,669,633.28元，与报告§7.1股票投资总额一致。

- 回测侧48只证券代码唯一；三只交集均来自指数投资。前十大持仓10只，证券代码交集为0。
- 本比较不能代表2026-11-02或2026-11-16同日实际组合的精确重合度；尚未取得同日全部基金实际持仓。
- 仅生成比较文件，未修改策略代码和原回测数据。
