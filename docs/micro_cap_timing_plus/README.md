# 微盘股择时增强策略（micro_cap_timing_plus）

来源：华福证券金融工程《微盘股择时——有效识别顶部风险&底部机遇的增强策略》（2026-08-11，PDF 见本目录）。

- 策略代码：`src/strategy/micro_cap_timing_plus.py`（信号 / 状态机 / 回测，纯 pandas）
- 数据重建：`src/utils/micro_cap_data.py`；数据拉取：`scripts/fetch_micro_cap_data.py`（缓存到 `data/micro_cap_timing_plus/`，约 3GB，已 gitignore）
- 运行示例：`examples/micro_cap_timing_plus.py`，结果在 `examples/micro_cap_timing_plus/`
- 测试：`python -m unittest tests.micro_cap_timing_plus_test`（仅模拟数据）

```bash
uv run python scripts/fetch_micro_cap_data.py     # Tushare 全市场日频 daily/daily_basic/moneyflow/stock_st，约 1 小时
uv run python examples/micro_cap_timing_plus.py
```

## 1. 研报内容总结

**标的**：万得微盘指数 8841431.WI（极小市值、低流动性，收益本质是市值因子 Beta；牛市平均 +66%、熊市平均 -25%）。回测 2016-01 至 2026-06，单边成本 0.1%，T 日收盘判断、T+1 开盘执行。

**三层优先级**：底部启动确认 > 顶部风险退出 > MA15 趋势锚。

| 模块 | 规则 |
|---|---|
| 趋势锚 | 收盘 > MA15 持有，否则空仓（MA5–MA20 遍历，MA15 最优） |
| 普通底部 | 近 10 日内曾同时满足 60 日回撤 ≥10%、距 MA15 ≤ -3%、RSI(7) ≤ 45；且资金流广度（2 日均值）≥55%、广度较前 5 日均值改善 ≥5%、主力净流入率（2 日均值）>0；且收盘突破前 3 日高点（大盘相对小盘 20 日收益差的 MA5 > 0 时提高到前 5 日高点）。触发后持有 20 日 |
| 危机底部 | 近 10 日 5 日跌幅 ≤ -10% 且 ATR 较 5 日前 +20%；60 日回撤 ≥35%、距 MA15 ≤ -20%、RSI ≤ 30；广度 ≥40%、改善 ≥5%、主力净流入率 ≥0；当日涨幅 ≥5%。针对 2024-02-08 |
| 顶部退出 | 扩散指数（站上自身 MA15 的成分股占比）20 日内曾 ≥0.85、较前 5 日均值回落 ≥0.05、资金广度或主力净流入率走弱，三者同时满足 → 空仓 10 日 |

**研报结论**：MA15 年化 22.96%、夏普 1.23、最大回撤 17.65%（买入持有 46.73%）；三段式综合 2016–2026 年化 30.60%、夏普 1.80、最大回撤 20.40%、卡玛 1.50；底部信号 16 次、15 日胜率 93.75%。截至 2026-07-31 策略转为多头。

## 2. 复现结果（2016-01-04 ~ 2026-06-30，单边 0.1%）

指数为本地重建（见下），因此与研报数字不可严格比较。

| 方案 | 年化 | 波动 | 夏普 | 最大回撤 | 持仓占比 |
|---|---|---|---|---|---|
| 买入持有（研报 20.31% / 29.54% / 0.69 / 46.73%） | 19.18% | 30.07% | 0.64 | 48.08% | 100% |
| MA15（研报 22.96% / 18.64% / 1.23 / 17.65%） | 20.40% | 19.13% | 1.07 | 19.14% | 63% |
| MA15 + 底部 | **25.61%** | 20.06% | 1.28 | 19.14% | 65% |
| MA15 + 顶部 | 4.88% | 14.14% | 0.35 | 28.26% | 33% |
| MA15 + 底部 + 顶部（研报 30.60% / 17.02% / 1.80 / 20.40%） | 18.62% | 16.64% | 1.12 | 21.17% | 42% |

**复现程度**

- 复现：买入持有基本吻合；MA 择时压缩回撤、提升夏普的效果成立；MA14–MA17 是平台，短均线（MA5–MA12）显著更差（MA14 夏普 1.10、MA15 1.07，MA5 0.61），与研报结论一致；底部增强有增量（年化 +5.2pp）；危机通道在 2024-02-08 触发，与研报一致。
- **未复现：顶部增强与综合策略 30.60%。** 本复现中顶部规则触发 422 个交易日（15.7%，243 个簇），反而拖累收益（有无顶部：18.6% vs 25.6%）。
- 底部：独立信号 17 次（研报 16 次），15 日胜率 82.4%（研报 93.75%）。2026-07-31 普通底部**未**在当日触发（广度 2 日均值 52.8% < 55%，差一点），2026-08-03 触发；截至 2026-10-23 持仓为空（收盘 11,907 < MA15 12,339）。

## 3. 数据 review

### 3.1 数据来源与重建方式

- **万得微盘指数在 Tushare 中不可得**（`index_daily('8841431.WI')` 为空）。用最小总市值 400 只（剔除北交所、ST、上市不足 60 个交易日、前日停牌）等权、逐日调仓、T-1 选股 T 日计收益合成，高/低点用成分 high/low 相对前收的均值近似。成分规则为**假设**，研报未披露。
- 数据：Tushare `daily`、`daily_basic`（total_mv）、`moneyflow`、`stock_st`、`stock_basic`，以及沪深300、中证2000 等指数；2015-10 至 2026-10-23，2684 个交易日，无缺失。
- 价格用 `pct_chg` 链式复权，避免除权跳变污染 MA15 / 扩散指数。

### 3.2 用研报披露数值对账（2026-07-16 ~ 07-31，共 12 个交易日）

| 指标 | 结果 | 结论 |
|---|---|---|
| 指数日收益 | 相关 0.997，平均绝对误差 0.2% | 重建指数可用 |
| 60 日回撤 | 相关 0.998，平均偏差 0.8pp（系统性偏深） | 可用 |
| RSI(7) | 相关 0.999，MAD 0.47；**简单均值法 MAD 7.8** | 研报文字称“上涨/下跌均值”，实际为 **Wilder 平滑**，代码已采用 |
| 主力净流入 | `net_mf_amount` 相关 0.89（广度）/0.91（净流入率）；自算“大单+超大单”相关为 **-0.55 / -0.27** | 必须用 `net_mf_amount` |
| 资金流广度幅度 | 相关 0.89 但 MAD 14pp，我的序列摆幅更大（9%–88% vs 研报 30%–79%） | 口径/成分差异，是 7/31 普通底部未触发的原因 |
| 大小盘 20 日收益差 | 沪深300 − 中证2000：MAD 1.3pp，7/31 为 14.2%（研报 12.46%）；沪深300 − 重建微盘：MAD 13pp、符号相反 | 研报的“小盘”实际接近中证2000 |
| 危机底部 2024-02-08 | 重建数据触发（涨幅 10.6%、广度 63%） | 一致 |

### 3.3 研报自身的不一致与风险点

1. **扩散指数表自相矛盾**：2024-11 案例表中 11/5 扩散指数 0.33、“5 日变化”-0.67，意味着前 5 日均值为 1.0，但表中前一日 11/4 只有 0.65；同期指数 11/5 上涨 2.4%，扩散指数 0.65→0.33→0.92 两天内剧烈跳动也不合理。表中两列不是同一序列，或存在数据错误。我用自己的扩散指数无法复现这些数值。
2. **顶部结论前后矛盾**：第 14 页称 0.85 阈值效果最优但 0.80/0.90 “明显变弱，缺乏参数平台，可能过拟合”；第 32 页又称“相邻参数同样排在前列，存在有效参数平台”。我的复现支持前者（甚至 0.90 更好）。
3. **同一参数两组业绩**：参数 0.85/0.05/exit10 在第 29 页网格表为年化 29.49%、最大回撤 -20.40%（与最终综合策略 20.40% 一致，应是叠加了 MA/底部的结果），在第 32 页“顶部增强策略”为年化 20.52%、回撤 46.45%。两处口径不同但表述相同，无法确认顶部规则单独贡献。
4. **变量名/文字错位**：因子表里 `main_net_ratio` 的算法写成了“广度 - 前 5 日广度均值”（那是 `flow_improvement`）；RSI 写简单均值实为 Wilder；均线偏离页面写 MA20、规则写 MA15、案例表写“20 日均线偏离”；文字中 MA15 最大回撤 17.55%/买入持有 45.73% 与表格 17.65%/46.73% 不符；买入持有年化 21.32%（至 7/20）与 20.31%（至 6/30）窗口不同。
5. **过拟合与小样本**：危机通道只针对 2024-02-08 一个事件；底部 16 次信号、15/16 胜率；参数按“前/后段胜率取小”在全样本内挑选，属样本内选择；底部持有 20 日但胜率按 15 日统计。2024 年单年收益 97.7%，综合策略很大一部分业绩来自这一年。
6. **可交易性**：微盘指数不能直接买入；复现假设 400 只微盘股每日调仓、按开盘价成交、无涨跌停/冲击成本，千一单边成本对微盘股明显偏低。万得微盘指数收益也包含大量等权日度再平衡收益。
7. **复现本身的局限**：成分规则、次新股阈值（未做敏感性）、指数高低点近似、Tushare 与万得资金流口径、风格差指数选择均为假设；资金广度差异直接影响底部信号个数与顶部触发频率，因此“顶部规则无效”这一结论只能说**在 Tushare 数据与上述假设下无法复现**，不等于证明研报错误。

### 3.4 建议

- 研报中可复核且稳健的部分：MA 择时的风险控制、底部增强（年化 +5pp）。
- 顶部规则、30.60% 的综合结果需要原始万得指数、因子序列后才能核实；在此之前不建议实盘依赖。
- 若要继续：用万得/聚源的微盘指数与主力资金口径替换重建数据，对成分规则（400 只 / 上市期限 / 市值口径）做敏感性，再复测顶部扩散指数的触发频率。
