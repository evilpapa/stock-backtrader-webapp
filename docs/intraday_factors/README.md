## 计算口径

- 报告第 7–8 页采用相邻**1 分钟简单收益率** `p[t]/p[t-1]-1`，而不是另一篇报告的 5 分钟对数收益率；偏度分母使用样本方差，三阶中心矩取均值。首条分钟线不计算跨夜收益。
- 默认仅接受 09:31–11:30 和 13:01–15:00 的结束时刻分钟线，至少 240 条；缺失整日不填充。Tushare 是否在所有历史日期都使用这一时间戳语义仍须用真实数据核实。
- 尾盘为 14:31–15:00，尾盘收益率的基准为 14:30 收盘价；大成交量为全天成交量最大 1/3 分钟，按时间顺序处理并列。大成交量收益率使用原序列相邻一分钟收益，避免跨选中时段计算收益。
- Amihud 按报告第 14 页的 `mean(abs(r)/(price*volume))`，零成交额分钟排除。这些缺失、平局与时间边界选择是实现假设，需要与研报原始数据对照。
- 上下行方差使用满足正、负收益条件的样本方差；尾盘相关性使用完整序列上的滞后或超前收益后再截取尾盘，边界处理均为待核验的实现假设。
- `smooth_factors(..., window=5)` 要求 5 个有效观测，缺少完整交易日不会自动感知，调用方须结合交易日历检验连续性。MA5 平滑方法见报告第 9 页。

## 冒烟用法

通过 DataHub 选择 Tushare，获取一只股票一个交易日；结果附带来源及数据版本元信息：

```bash
.venv/bin/python examples/intraday_factors.py --symbol 600000.SH --date 2021-01-04 --output examples/intraday_factors/sample.csv
```

需要已配置 `TUSHARE_TOKEN`、安装依赖并开通股票历史分钟接口。实测账户返回 `stk_mins` 每分钟 1 次限流，未能获取校验样本。接口说明：<https://tushare.pro/document/2?doc_id=370>。应使用有限的、可恢复的分段下载和持久缓存后，再进行大规模研究。

也可以明确选择 XtQuant 数据源，默认下载缺失的历史分钟数据；加 `--no-download` 仅读取本地缓存。此处 `start` 是示例，必须先对照实际 QMT 分钟时间戳和对应时段确认，再选择 `start` 或 `end`：

```bash
.venv/bin/python examples/intraday_factors.py --data-source xtquant --bar-time start --symbol 600000.SH --date 2021-01-04 --output examples/intraday_factors/xtquant_sample.csv
```

脚本禁用 `fill_data`，避免补齐数据被当作真实分钟成交；选用 `start` 时将时间加一分钟后计算。结果元信息保存数据源、原始时间语义选择、数据版本和未复权口径。XtQuant 分钟成交量按 DataHub 的 `units.xtquant_minute` 配置转换，实际桥接环境的单位须核验，尤其影响 Amihud 数值。

2026-11-08 利用本机桥接缓存中 `000001.SZ` 2026-11-06 的单日 241 条分钟行情进行了冒烟计算，剔除 09:30 集合竞价占位后使用 240 条；结果见 `examples/intraday_factors/xtquant_000001_20261106.csv`。样本中分钟成交额除以价格与原始成交量乘积约为 100，DataHub 因此按 `units.xtquant_minute` 将该桥接股票分钟成交量由手换算为股。09:31 至 15:00 标签按分钟末处理仍为实现假设，需进一步对照原始时段。该样本只验证因子可计算，不代表选股或回测结果。桥接现已恢复；抽样显示三只股票 2026 年 1 月各有 20 天分钟数据，而 2021 和 2025 抽样日期为空，不能据此推断全部股票的覆盖范围。

## 周频小样本研究

运行 `.venv/bin/python examples/intraday_factor_weekly.py`：通过 DataHub 读取
Tushare 交易日历与 QMT 已有分钟数据（`download=False`、`fill_data=False`），
按 2025-12-31 的中证500权重快照的证券代码排序，取前 30 只，研究 2026 年 1 月。
`--limit` 可调整数量。DataHub SQLite Repository 缓存输入；每日因子、周频研究表和
来源元信息存于 `examples/intraday_factors/weekly_sample/`。仅使用完整 240 分钟的
股票日。日历对齐后以最近 5 个交易日的日因子均值作为周末信号；第一个未来交易日
首分钟开盘买入，5 个交易日后首分钟开盘计算毛收益，输出 Spearman 秩 IC 和十组等权
收益。先以信号日可见因子值分组，平局按证券代码顺序处理；再关联未来收益，每期至少 10 个有效收益，结果提供各组有效数。未来价格缺失会造成收益统计样本偏差。

**这只是流程验证，不能当作可交易的报告回测**：首分钟开盘价是执行价格代理，不一定
等于正式开盘价；数据未复权、未处理分红等公司行为，也未过滤 ST、上市不满一年、
交易日涨跌停或停牌，未计手续费、滑点和容量。完整分钟缺失只意味着被排除，不能
直接判定为停牌。成分采用事前月末快照代理，发布时间和精确生效日期未知；固定按代码
选前 30 只存在样本选择偏差。该极短样本不能用于判断因子有效性。回测模块和项目规定
的佣金模型尚未接入这个旧示例；下方竞价合并示例另有简化佣金模拟。

本机实际运行：候选 30 只中 29 只有完整日数据，20 个交易日共 580 个股票日；
2026-01-09、2026-01-16 两个信号日各产生 39 行因子结果，每个截面有效数为
27–29 只。后续信号因样本末尾缺少完整持有期未输出。

扩展样本通过 `.venv/bin/python examples/intraday_factor_weekly.py --end 2026-03-31
--output-dir examples/intraday_factors/weekly_quarter` 得到：29 只证券、56 个交易日、
1,596 个完整股票日，10 个信号日、390 条因子记录，截面有效收益数 23–29。
固定使用 2025-12-31 快照代码排序的前 30 只，不会随指数调样，证券 000559.SZ

## 竞价因子与周度模拟

通过 `.venv/bin/python examples/intraday_auction_weekly.py` 将
`weekly_quarter/daily_factors.parquet` 与 `AuctionTickRepository` 的本地逐日 Tick
合并，输出 `weekly_auction/` 中的每日因子、快照质量记录、十组和 IC、示例净值、
成交记录及来源 manifest。2026 年一季度固定样本 29 只、1596 股票日，10 个可观测
完整持有期的周度截面；这不是全市场或完整的中证500研究。

每阶段至少 2 个有效快照：`bid1=ask1=last>0`，`last` 在正数且有效的价格上下限内。
阶段边界为 `[09:15,09:20)`、`[09:20,09:25)`；每阶段求 `last` 最高和最低。
9:25 后 `open` 必须有唯一正值，`pre_close` 必须有唯一正值。四个价格因子是
`open/high-1`、`open/low-1`；报告表 13 中 AL2 的文字重复写成最高价，此处按名称
解释为最低价。报告只写阶段振幅，未明确分母；此处采用 `(high-low)/pre_close`，
属于待核对假设。隔夜收益为 `open/pre_close-1`。阶段无足够有效数据、开盘价或
前收不唯一时对应因子为 NaN，不使用零或未来行情填充。报价有效规则、快照遗漏与
前收除权口径均需供应商确认。

研究期收益采用正式竞价开盘价而不是首分钟价格。2026-03-31 样本 29 只的竞价开盘价
及参考前收都与 Tushare 不复权日线一致；一季度 1596 个股票日中，1091 次竞价开盘
价与首分钟开盘价不同。不同时间粒度的价格本来可能不同，不能用前者自动验证后者。

`illustrative_equity.csv` 和 `illustrative_trades.csv` 来自非常简化的模拟：
默认 MA5 的 `ret_open2AL1` 从大到小选前 10%、每周信号、下一交易日竞价开盘调仓，
100 股一手，现金约束，佣金使用 `ChinaStockCommission` 默认值；无股票时保留现金。
无法取得当日开盘价时不能交易，持仓估值沿用最近开盘价并标记。没有建模停牌、
涨跌停、股利、除权、印花税、滑点及容量，开盘价格不保证成交；交易决策同价、
买入按因子顺序占用现金。因此结果仅检验流程，不可视为实盘或报告回测，不能和
报告的双边千分之二费用直接比较。


## 2021–2026 动态股票池竞价因子研究

```bash
.venv/bin/python scripts/build_auction_factor_history.py --start 2021-01-04 --end 2026-02-27
.venv/bin/python examples/auction_history_research.py --factor-dir data/intraday_factors/auction_history_csv/daily --output-dir examples/intraday_factors/auction_history_csv
```

第一步从本地竞价 Tick 仓库生成可断点续跑的每日因子缓存；每日元信息记录源文件、
证券集合和实现代码的哈希。第二步读取 Tushare 本地日线、历史 ST、证券基础信息、
中证500指数日线与月度成分快照，输出到 `examples/intraday_factors/auction_history_csv/`：
`factor_summary.csv`、`weekly_research.csv`、`coverage.parquet`、
`universe_snapshots.csv` 和 `manifest.json`。原始 ST 日文件缺失或为空时中止，
不会将缺失数据当作全市场无 ST。

样本覆盖 2021-01-04 至 2026-02-27 共 1246 个交易日，成分快照共涉及 930 只股票。
先以月末快照日期加 31 个自然日作为假定可用日期，再在信号日选最近一期可用快照。
这只是延迟使用月度权重的近似，快照实际公布日期未经核实，月内成分变动也无法还原，
因此仍有时点偏差风险。信号日剔除历史 ST、上市未满一年、已退市、无日线成交记录，
以及竞价开盘价或参考前收与日线不一致的证券；基础资料的完整性取决于本地缓存。

七个因子沿用上文的六个竞价路径因子和隔夜收益，每个因子取最近五个交易日的均值，
按周在信号日可见的合格股票中升序分十组，再关联未来收益并计算 Spearman 秩 IC。
持有期为信号后第 1 个交易日开盘至第 6 个交易日开盘；指数开盘收益作为同期参考。
2021-02-05 至 2026-02-06 共 257 个信号周，各因子有效截面中位数约 471–492 只。
平均秩 IC 分别为 `diverge_A1=-0.0327`、`diverge_A2=-0.0410`、
`ret_open2AH1=0.0325`、`ret_open2AH2=0.0255`、`ret_open2AL1=-0.0085`、
`ret_open2AL2=-0.0205`、`ret_overnight=-0.0036`。这与此前固定小样本不能直接
比较，尤其不应据此假定小样本中使用的 `ret_open2AL1` 高值方向在长期成立。

持有期收益用相邻成交日 `close / pre_close` 累乘近似处理除权，异常参考价跨区间时
不计算收益；这不是正式复权因子或公司行为现金账。未来价格缺失的股票不计入收益，
可能产生缺失样本偏差。结果未建模实际成交、停牌期间持仓、涨跌停、分红、交易费用、
滑点和容量，不是可交易净值回测。此研究只覆盖七个竞价相关因子，39 个分钟因子
尚无相应多年行情，不能视为报告 46 因子的完整复现。

## 历史分钟行情准备

以下命令通过 DataHub 的 XtQuant Adapter 仅读取 QMT 已有的未复权 1 分钟缓存，保留
OHLC、成交量、成交额和来源等字段，禁用补齐。默认选中证500历史快照涉及的 930 只证券，
按月和 5 只证券分批写入 `data/intraday_factors/minute_history/`，重复运行会从已保存
的精确请求继续。该并集用于准备行情，并非在每个历史日期都将这 930 只纳入选股池。

```bash
.venv/bin/python scripts/build_intraday_minute_history.py --start 2025-11-01 --end 2025-11-30 --batch-size 50
.venv/bin/python scripts/summarize_intraday_minute_history.py --start 2025-11-01 --end 2025-11-30 --batch-size 50
# 桥接恢复后，使用更小批量尝试后续月份
.venv/bin/python scripts/build_intraday_minute_history.py --start 2025-12-01 --end 2026-02-27 --batch-size 5
```

汇总脚本生成逐证券逐日 `coverage.parquet` 与 `coverage_summary.csv`。交易日期来自已有
Tushare 日线文件；`daily_traded` 用日线成交量标记，`batch_cached` 表示该批次已处理，
`complete_240` 要求 09:31–11:30、13:01–15:00 各分钟恰好一条，价格、成交量有效且
首分钟开盘价有效。统计以分钟末标签为假设，并未独立确认 XtQuant 时间戳语义。
`complete_240` 是输入完整性检查，不意味着相应因子值一定有效；零方差等情况可导致
因子为缺失。采集时间范围和批次设置必须与汇总参数一致；空缓存需要 `--refresh`
重新读取，不能把空结果解释为停牌。`--download` 会请求终端下载，但本机 2021 年
单股实测返回终端未绑定下载通道，不能保证取得较早行情。不同选项对应不同缓存键。

2026-11-09 本机实际整理 2025 年 11 月：930 只证券、20 个缓存日线交易日、19 个
批次、3,214,732 条分钟记录；817 只证券有至少一个完整分钟日，合计 12,984 个完整
股票日。日线标记有成交但未满足完整分钟条件的有 5,201 个股票日，不能解释为停牌。
另用 2025-12-31 快照前 50 只的 2026 年 1 月行情，生成 1,000 个完整股票日的 39
个因子冒烟结果，位于 `examples/intraday_factors/minute_history_probe_factors.parquet`。
2025 年 12 月大批次请求后桥接超时，随后 5 只股票请求及 ping 也超时；此时没有将
超时存为空批次。较早历史单股下载还因终端下载通道未绑定而失败；因此目前并无
2021–2026 年完整分钟行情。桥接状态恢复后可用上述小批量命令续取。


## 2021–2025 Tushare 分钟下载任务

2026-11-09 实测 `stk_mins` 可返回 600000.SH 在 2021-01-04 的行情，但账户先后
返回每分钟 1 次和每小时 1 次的频率限制；必须以更严格的每小时限制为准。QMT 对同日
尝试下载后返回空数据，桥接提示该范围位于已有最新数据之前的追加限制区间，不能认为
历史行情已取得。不要通过删除现有 QMT 文件来处理这个问题。

`scripts/build_tushare_minute_history.py` 使用 DataHub 的 Tushare Adapter，按最多
32 个交易日、一只证券分批，防止单次 8000 行截断；未复权，时间语义使用 Tushare
的分钟末口径，保存数据源、版本、请求及文件哈希。使用滞后 31 自然日的月度权重
快照近似确定每段取数范围，并额外加入未来 5 个交易日可能需要的证券以预热因子；
取数集合不能作为信号日成分。2021–2025 年本地日线文件日期与 Tushare 上交所交易
日历已逐日比较，均为 1,212 天。任务计划 38 段、891 个不同证券、19,454 个请求。
这不覆盖从未被上述近似股票池选中的证券。

默认间隔 3,665 秒，理论上限速等待就需约 825 天；接口权限、小时/日额度、服务中断
及实际返回数据可能进一步延长或中止任务。后台任务每次请求前持久化上次请求时刻，
已保存批次可断点续跑；遇到小时或更长周期的频率限制、权限和其他错误会停止，
不会把错误保存为空数据。空响应只表示供应商此次返回空数据，不代表停牌。

```bash
# 查看任务及近期日志
systemctl --user status intraday-tushare-history.service
journalctl --user -u intraday-tushare-history.service -n 30 --no-pager
cat data/intraday_factors/tushare_minute_history/worker.log
# 需要停止本机后台采集时
systemctl --user stop intraday-tushare-history.service
# 手工断点续跑（避免与后台任务同时执行）
.venv/bin/python scripts/build_tushare_minute_history.py
```

后台为 transient user service；机器重启、用户会话或服务错误可能终止它，不保证跨
重启自动恢复。要在可接受的时间内取得全部历史，需要提高 Tushare 分钟接口额度或
提供可批量获取 2021–2025 历史分钟线的其他已授权来源。

哪个 QMT 客户端、哪个行情数据目录以及桥接连接的终端，不能从空返回或该占位结果

## 本地 2020–2026 分钟 Parquet

`data/tick_1m_parquet` 指向本地数据盘：2020–2025 各年为
`year=YYYY/YYYY.parquet` 单文件；2026 为
`year=2026/month=MM/day=DD/YYYYMMDD.parquet`，本次发现 203 个日文件，截止
2026-11-06。字段为 `ts_code`、`trade_time`、OHLC、`vol` 和 `amount`。
`LocalMinuteRepository` 以 DataHub 标准请求只读单个交易日、指定证券，并记录
源文件 SHA-256；年度文件较大，哈希采用流式计算并在同一进程内复用。

数据提供方、精确复权口径和分钟时间标签定义尚未取得权威说明。以 000001.SZ
2021-01-04 与 2026-01-05 为样本，分钟成交量和成交额的单日合计与本地
不复权日线相符（按股和元）；价格也与日线开收盘相符。2026-01-05 与 QMT 重叠
样本的分钟数据接近但并不完全相同，不能仅靠此确认分钟边界。当前以分钟末标签
**假设**选取 09:31–11:30、13:01–15:00，并包含 15:00 收盘竞价；不使用 09:30
额外记录。该假设会影响收益、尾盘及价量相关因子，跨年份一致性仍需核验。
仅在上述 240 个时刻恰好各有一条、价格及成交量有效且全天有成交的股票日计算
39 个分钟因子，不对缺失分钟补值。时间区间与起始/结束标签的差异不得据此视为已解决。
