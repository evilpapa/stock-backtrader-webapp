来源：国泰海通证券金融工程《正收益策略系列01：如何通过估值、盈利质量和资本开支效率构建自由现金流策略》（2026-10-17）。
研报库路径：`/data3/smb/fin-quant-reports/国泰君安/2026-10-17_国泰海通证券_正收益策略系列01：如何通过估值、盈利质量和资本开支效率构建自由现金流策略.pdf`（版权原因未复制进仓库）。

## 1. 研报方法

**候选池**（照搬中证自由现金流 932365 选样，pp.15-16）：

1. 样本空间：剔除 ST/*ST；科创板上市满 1 年、北交所满 2 年、其他满 1 个季度；
2. 剔除过去一年日均成交额后 20%；
3. 剔除中证一级金融、地产；按盈利质量 =（经营现金流 TTM − 营业利润 TTM）/ 总资产 剔除后 20%；
4. 要求自由现金流 TTM > 0、EV > 0、近 5 年经营现金流净额均 > 0。

**因子**（候选池内测试，最终各类选一个，pp.15-21）：

| 类别 | 入选因子 | 定义 |
|---|---|---|
| 估值 | 自由现金流率1 | FCF / EV1，EV1 = 市值 + 总负债 − 货币资金 − 交易性金融资产 |
| 盈利质量 | 自由现金流 EBITDA 比 | FCF / EBITDA |
| 资本开支效率 | 资本开支效率 ROEPB | 资本开支成长性 × ROE / PB；成长性 = 前 3–5 年资本开支均值 / 近 2 年均值 |

**复合模型**：三因子合成后取前 100，自由现金流加权、单只上限 10%，季度调样（3/6/9/12 月第二个周五的下一交易日）。
研报结论：2014-01 ~ 2026-08-07 年化 **19.43%**，相对中证现金流全收益超额 1.27%、中证红利全收益 7.46%、沪深 300 全收益 13.71%；最大回撤 43%（2015-07 ~ 2016）。
指数复现部分：年化 17.32%，相对官方跟踪误差 1.88%，2024-12 起成分重合度均值 93%。

## 2. 复现中的实现假设

研报未说明的细节，按下列口径实现：

| 项目 | 本实现 | 说明 |
|---|---|---|
| 行业 | 中信一级（Tushare `ci_index_member`，含历史 in/out） | 研报用中证一级；Tushare 无中证行业历史 |
| FCF | 经营现金流净额 − 购建固定/无形/长期资产支付的现金（毛额） | 毛额与官方成分重合度 79.5%，扣处置收回的净额为 77.6% |
| EBITDA | 营业利润 + 财务费用 + 折旧摊销（TTM） | Tushare `ebitda` 字段在季报缺失；折旧摊销只在半年报/年报披露，Q1/Q3 用最近一期 |
| TTM | 当期累计 + 上年年报 − 上年同期累计 | |
| 财务时点 | 三表最晚的首次公告日 `f_ann_date`；更正报告用更正数值、首次公告日 | 不使用未来数据 |
| 定样截止 | 调样月上月最后一个交易日 | 重合度 81.9%，比第二个周五当日（79.5%）更高 |
| 复合因子 | 三因子候选池内百分位排名等权平均，至少 2 个因子非空 | 研报未披露合成权重 |
| 收益 | `daily.pct_chg` 链式累乘（即分红再投资的全收益） | 与全收益指数对比 |
| 成本 | 万 0.854 双边（`src/utils/commission.py` 费率），不计印花税/冲击 | 季度单边换手约 30% |

## 3. 复现结果

### 3.1 与研报同区间（2014-01-02 ~ 2026-08-07）

| 方案 | 年化 | 波动 | 夏普 | 最大回撤 | 研报 |
|---|---|---|---|---|---|
| 复现指数（FCF/EV 前 100，FCF 加权） | 17.93% | 22.78% | 0.79 | 42.51% | 17.32% |
| **增强策略（复合因子前 100，FCF 加权）** | **18.91%** | 23.05% | 0.82 | 42.59% | 19.43% / 43% |
| 增强策略（等权） | 15.42% | 24.24% | 0.64 | 46.98% | — |
| 中证现金流全收益 | 19.05% | 22.64% | 0.84 | 44.06% | 18.16% |
| 中证红利全收益 | 12.58% | 20.50% | 0.61 | 45.66% | 11.97% |
| 沪深 300 全收益 | 8.65% | 21.40% | 0.40 | 46.06% | 5.72% |

增强策略超额年化：vs 中证现金流全收益 **−0.1%**（研报 +1.27%），vs 中证红利全收益 +6.3%（研报 +7.46%），vs 300 现金流 +8.4%（+5.25%），vs 500 现金流 +8.0%（+5.87%），vs 沪深 300 全收益 +10.3%（+13.71%）。
注意：中证现金流全收益在本区间实际年化 19.05%，高于研报所写的 18.16%；两者区间起点的口径可能不同。

**指数复现精度**：相对 932365CNY010 跟踪误差 3.35%（研报 1.88%）；与 Tushare 官方成分（2024-12 起 8 期）重合度 73%–89%，均值 82%（研报 93%）。差距主要来自行业分类（中信 vs 中证）和财务口径。

2014 57.8% / 57.8%，2015 20.2% / 19.4%，2016 −3.1% / −0.9%，2017 46.7% / 41.8%，2018 −15.3% / −15.2%，2019 29.9% / 25.5%，2020 15.2% / 13.9%，2021 45.8% / 35.5%，2022 1.7% / −2.8%，2023 10.3% / 20.8%，2024 28.9% / 40.9%，2025 21.7% / 19.6%，2026 YTD（至 2026-08-07）−8.1% / −4.7%。

## 4. 复现评价

- **复现成功的部分**：自由现金流指数编制逻辑可以落地。复现指数年化 17.9%，研报 17.3%，官方指数 19.1%。三个入选因子在候选池内单调有效，增强策略的绝对收益（18.9%，研报 19.4%）、最大回撤（42.6%，研报 43%）与研报基本吻合。相对红利、规模、300/500 现金流指数，超额都很显著。
- **未复现的部分**：研报称增强策略比官方中证现金流全收益高 1.27%/年，本复现约为 0。增强层相对本地复现指数仍有 +1.0%/年，但本地复现指数本身比官方指数低约 1.1%/年（跟踪误差 3.4%，成分重合度 82%）。所以“增强”这一层有增量，但在本数据口径下不足以弥补选样误差。
- **增强层的稳定性**：增量集中在 2017、2019–2021、2022；2023–2024 大幅跑输。等权版本明显差于 FCF 加权，说明收益很大程度来自“FCF 绝对值加权”带来的大盘、资源、公用事业暴露，而非因子本身。
