# 20 万元账户模拟

运行：先执行 `uv run python -m scripts.fetch_citic_industry_history` 按中信一级行业及 Y/N 状态分批获取成员，然后执行 `uv run python -m examples.free_cash_flow_account`。结果默认写入 `examples/free_cash_flow/account_industry/`，不会连接交易账户或发送委托；原目录 `examples/free_cash_flow/account/` 保留旧结果。

## 对照与规则

- 对比 20、25、30、50、100 只：复合因子排名，按自由现金流加权，单股目标上限 10%。
- 25、30 只各增加单股目标上限 8%、中信一级行业目标上限 25% 的组合；若约束容量不足，剩余现金不分配。对缺失行业统一视为“未知行业”。
- 同时测试约束加排名缓冲：分别保留排名前 40、45 的老持仓，优先保留排名靠前的老持仓；剩余名额由前 25、30 名新股依次填入，不强制用新股替换缓冲内老股。失败或未成交持仓可能导致实际持仓数暂时超限。
- 初始 20 万元；每季度第二个周五后首个交易日开盘模拟成交；买卖及持仓统一限制为 100 股整数倍。先卖后买，按证券代码顺序处理；不够现金时缩量。目标为上月末可得数据生成。这是本实验的统一简化约束，并非所有 A 股板块买卖与零股处理规则。
- 每笔非零成交使用 `ChinaStockCommission` 的万 0.854、最低 5 元；另外假设卖出印花税 0.05%、单边滑点 0.1%。**印花税在整个历史期统一使用该假设，不是历史税率**；未计过户费、分红税、冲击成本。滑点不是佣金，体现在成交价中。
- 停牌/无价格不成交；开盘较前收上涨超过 9.8% 不买、下跌超过 9.8% 不卖，是保守的粗略代理，不能准确覆盖 ST、创业板、科创板、北交所及历史涨跌停规则；未模拟排队、部分成交、T+1、真实申报单位差异和退市清算，不能作为实盘成交保证。
- 除权除息使用上一收盘价/当日前收价折算理论持仓，向下取整手后将剩余等价价值计入现金（每日 `corporate_action_cash`），以保持折算前后估值连续。这是无交易费用的研究近似，不是真实分红、送转或卖出流水；可能改变现金仓位，亦不包含分红税。
- 每期按公告日截断财务版本后再计算 TTM，但供应商可能覆盖原始公告版本；原有缓存不足以保证严格 PIT。行业分类不使用未来的最新行业回填。样本池不是严格的中证全指历史样本，且停牌估值沿用最近收盘价，退市/数据缺失可能高估收益。
- 目标权重约束不是成交后硬约束：价格漂移、滑点、整数手、停牌及卖出失败可能造成实际权重超限。

## 分行业获取与历史矩阵

分批输入为 `citic_member.duckdb` 中的 30 个一级行业代码，通过 DataHub `ci_index_member` 对每个代码分别请求在编、调出数据；结果保存在 `data/free_cash_flow/reference/citic_industry_batches/` 和 `citic_member_by_industry.duckdb`。`citic_member_by_industry_manifest.json` 记录数据源、获取时间、行业代码种子及各批次数量；行业代码来自既有缓存，并非独立权威的完整行业目录。Tushare 的 `index_classify` 实测 `src=CI` 返回空结果。

回测使用每个定样截止日的 `in_date <= date < out_date` 区间构造 `industry_matrix.duckdb`（每行对应一个截止日，每只证券占一列）。缺少起始日期或重叠的不同一级行业不会猜测；缺少结束日期视为开放区间。剔除日为不含当天的约定尚需向供应商核实。`industry_coverage.csv` 给出各期全市场和候选池的已知行业数量。

2026-11-05 拉取对账：旧缓存 6,745 行、5,740 只；分行业新数据 6,750 行、5,741 只。2013 至 2019 各年末可唯一分类股票数分别为 1,231、1,277、1,439、1,508、1,867、2,010、3,637，**与原缓存逐年相同**。因此分批拉取并未补足这段历史；仍需从拥有历史分类的数据源补齐，不能用未来行业回填。

按分行业数据重新运行账户回测后，所有版本的年化收益和最大回撤与上一轮在所输出精度内相同。按定样截止日统计，2014–2019 各年候选池平均行业覆盖率分别为 45.7%、40.3%、43.7%、47.3%、47.5%、48.9%；2020–2026 年为 99.3%–100%。覆盖率按各期股票数量计算，不能与下文的持仓权重覆盖率直接比较。完整矩阵和每期计数见新输出目录。

### 逐股查询验证

通过 `uv run python -m scripts.fetch_citic_industry_by_stock --workers 2` 逐股查询股票基础缓存中的合法代码，分别获取 `is_new=Y/N` 并保存到 `data/free_cash_flow/reference/citic_stock_batches/`；各分片可断点续传，全部完成后合并为 `citic_member_by_stock.duckdb`，数据来源和批次见同目录 manifest。该股票池自身可能有缺漏，缓存不自动刷新。使用 `uv run python -m scripts.validate_citic_industry_by_stock` 生成逐股矩阵和年末与逐行业数据的覆盖、冲突对比；输出至 `examples/free_cash_flow/industry_validation/`。相同接口以不同参数查询不能证明数据完整性。

2026-11-05 完成对 5,918 只合法证券的 11,836 个状态分片请求，得到 6,750 条去重成员记录，与逐行业结果完全相同。按基础信息中的上市、退市日期限定股票池后，2013–2025 每年末两种方式均无单边新增分类或行业差异。例如 2014 年末分别覆盖 1,277/2,592 只，2018 年末覆盖 2,009/3,567 只；分母是本地股票基础缓存中的上市股票，不保证历史完整性。逐股查询没有补齐早年缺口；这说明本次查询参数切换无改善，不足以证明供应商不存在其他历史数据接口。

## 输出

- `industry_matrix.duckdb` 和 `industry_coverage.csv` 分别保存每期定样时点行业矩阵，以及市场、候选池覆盖率计数。
- `metrics.csv`：扣上述交易摩擦后收益、回撤、实际持股权重、费用及现金比例。
- `yearly.csv`：逐年策略、现金流全收益基准及两者直接相减的差额；起止不完整年度不能当完整年度比较。
- `daily.csv`：每日资产、现金、持仓数、收益和基准收益。
- `orders.csv`：历史模拟成交，不含未成交委托；`latest_rebalance_orders.csv` 是历史最后一次调仓成交。`initial_orders_latest_signal.csv` 为最近一次信号从 20 万元空仓独立模拟建仓，`initial_positions_latest_signal.csv` 为对应持仓；使用当时的历史开盘价，均不是当前建议订单。
- `positions.csv`、`industry_weights.csv`：每次调仓执行后的实际个股与行业权重；不代表季度期间逐日权重峰值。

本结果为研究用途而非投资建议；因上述简化和财务修订数据限制，不应直接据此决定实际委托。
