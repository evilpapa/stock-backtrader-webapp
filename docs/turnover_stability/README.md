## 1. 研报方法与因子定义

月底截面计算以下 5 个换手率选股因子，均在横截面上做 MAD 去极值、市值中性化（或风格与行业中性化）与标准化；**因子方向均为“越小越好”**（G1 为因子值最小的 10% 多头组，G10 为因子值最大的 10% 空头组）：

| 因子 | 原文出处 | 构造定义（默认 $K=20,\; X=40$） | 中性化口径 |
| --- | --- | --- | --- |
| `Turn20` | 第 1 节，pp.4–5 | 过去 $K$ 个交易日日均换手率 | $\ln(\text{总市值})$ OLS 残差 |
| `PctTurn20` | 第 2.1 节，pp.6–7 | 过去 $K$ 日每日“当日换手率 / 该日前 $X$ 日换手率均值 − 1”的均值 | $\ln(\text{总市值})$ OLS 残差 |
| `STR` | 第 2.2 节，pp.7–9 | 过去 $K$ 个交易日换手率样本标准差（量稳换手率） | $\ln(\text{总市值})$ OLS 残差 |
| `SCR` | 第 3 节，pp.9–11 | 过去 $K$ 日换手率标准差 / 再往前 $X$ 日换手率标准差 − 1（量稳换手率变化率） | $\ln(\text{总市值})$ OLS 残差 |
| `PureSCR` | 第 4.1 节，pp.12–13 | 在 `SCR` 基础上剔除常用风格与一级行业影响 | 风格代理因子 + 中信一级行业 OLS 残差 |

## 2. 数据来源与实现口径

| 项目 | 本复现口径 | 说明 |
| --- | --- | --- |
| 日频行情与换手 | 本地 DataHub 缓存 `data/micro_cap_timing_plus/raw/{daily,daily_basic,stock_st}` | 覆盖 `2012-10-08 ~ 2026-11-02`（3,417 交易日），前 60 日用于预热，首个信号为 `2012-12-31`，首个持仓月为 `2013-01` |
| 指数成分权重 | 经 `DataHubClient.query("index_weight")` 拉取并缓存至 `data/turnover_stability/cache/` | 沪深 300（`000300.SH`）与中证 500（`000905.SH`）按半年分片获取，截面严格取 `trade_date <= date` 最近一期 |
| 股票池过滤 | 剔除当日 ST/*ST、上市不满 120 自然日、当日停牌/换手率 $\le 0$ 或市值缺失个股 | 过去 $K$ 日、$X$ 日有效换手天数均要求达到窗口长度的 75% 以上 |
| 去极值与标准化 | 横截面 $5 \times \text{MAD}$ 缩尾，回归残差做 z-score 标准化 | 严格只使用调仓日收盘及之前数据，零前视偏差 |
| 纯净 SCR 风格控制 | 市值、非线性市值、BP、EP、252-21 动量、20 日反转、60 日波动率、20 日对数换手率 + 中信一级行业（时点归属） | 原文使用商业 Barra CNE5 与 28 个申万一级行业；本复现以日频风格代理与中信一级行业替代 |
| 收益与手续费 | 月底收盘定样，次月首个交易日起计收益、月内权重随价格漂移；纯多头回测按 `src/utils/commission.py` 扣除双边各 **万 0.854** 佣金 | 单因子 10 分组多空检验按研报惯例不计交易成本；多空月收益采用 $(1+r_{G1})/(1+r_{G10})-1$ |
| 绩效指标口径 | 累计收益、年化收益、年化波动、最大回撤、夏普比率（无风险利率为 0）、卡玛比率 | 日频组合按 252 交易日年化，月频单因子表按 12 月年化 |

## 4. 复现评价

1. **高度吻合原文的部分**：在研报重叠窗口（2013–2021.10）内，全 A 市场上 `STR` 与 `SCR` 的 10 分组单调性、多空年化收益（`37.9%` / `18.6%`）、最大回撤（`14.0%` / `8.2%`）、空头强于多头的收益分解结构、参数敏感性平台特征，以及 `SCR` 压缩高换手空头组离散度（图 9）的核心现象均得到完整复现。
2. **发表后样本外（2021.11–2026.10）的关键分化**：
   - **`STR`（量稳换手率）生命力极强**：无论在全 A（多头 Top10% 年化 `24.86%`、Top50 年化 `28.73%`）还是沪深 300（Top10% 年化 `6.25%`、最大回撤仅 `18.75%`）中，样本外均大幅跑赢基准，且换手率显著低于 `SCR`（月单边约 48%–55%）。
   - **`SCR`（量稳换手率变化率）在样本外与大盘股中明显衰减**：作为换手率波动率的二阶变化率，`SCR` 月均单边换手高达 `80%–93%`，2021 年底发表后全 A 多空 IR 从 `1.94` 降至 `0.98`，剔除风格与行业后的 `PureSCR` 转负（IR `−1.09`），沪深 300 内也跑输指数（年化 `−3.63%` vs `−1.67%`）。
3. **实盘落地启示**：若构建纯多头月频选股策略，建议优先以 **`STR`（或低换手 + `STR`）** 作为核心量价稳定性底座，同时关注实际交易中的涨跌停不可成交、小市值容量与冲击成本（本回测仅计万 0.854 佣金，未含印花税与滑点）。
